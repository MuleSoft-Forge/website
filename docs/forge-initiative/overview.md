# Overview

## Background

## Origin Story

In September 2007, [MuleSource launched MuleForge](https://www.techmonitor.ai/technology/mulesource_forges_open_source_community), a shared community environment for MuleSoft assets.

In February 2025, a LinkedIn outreach seeking assistance to develop a MuleSoft Java SDK Connector led to the revival of MuleSoft Forge.

> Hello MuleSoft Community!
>
> [View LinkedIn Post](https://www.linkedin.com/posts/georgejeffcock_mulesoft-opensource-communitypower-activity-7295776860934709248-GBzb)

The need for a centralized location to host community assets became clear. Personal and partner-hosted assets, while valuable, have contributed to **asset sprawl** across the ecosystem. The MuleSoft IDP Connector, led by [George Jeffcock](https://www.linkedin.com/in/georgejeffcock) and [Reza Lexén](https://www.linkedin.com/in/reznas/), initiated this development.
