# Overview

## Background

<Hint type="success">
Did you know? **Origin Story**

Sept 2007 - [MuleSource has launched MuleForge, a shared community environment](https://www.techmonitor.ai/technology/mulesource_forges_open_source_community)

In February 2025, a single LinkedIn outreach seeking assistance to develop a MuleSoft Java SDK Connector led to the revival of MuleSoft Forge.

It became apparent that we needed a location to host this asset for others, rather than for personal or partner use. While such use is great, it has led to what is known as **asset sprawl**. The MuleSoft IDP Connector initiated the development, led by [George Jeffcock](https://www.linkedin.com/in/georgejeffcock) and [Reza Lexén](https://www.linkedin.com/in/reznas/).
